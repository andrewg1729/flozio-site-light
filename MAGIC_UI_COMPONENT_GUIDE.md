# Magic UI component review

Generated from the local catalog and official Magic UI docs/source snapshot at commit efe76fc5755eca1142dd4f74c1d6f0ace2887e3c. Use this as a searchable research index, not as automatic approval to put a component on the Flozio homepage. The current catalog has 85 component entries and 170 official example variants.

## Evidence and limitations

All 170/170 listed example TSX files were found in the pinned source checkout and statically extracted: source hash, imports, component JSX, configured props, and detectable pointer/click/scroll/animation signals. All 170/170 entries map to a specific preview ID in the matching docs page. The source fields are an index for inspection; use the linked TSX for full implementation details.

The browser pass opened all 170 mapped previews across 77 docs routes, brought each into view, inspected active animation and transition state, sampled before, activation, and follow-up frames; checked computed motion styles, SVG attributes, and canvas fingerprints; and applied profile-matched pointer-sweep, hover, click, press-and-hold, drag, or scroll input. Animated Beam gets a 2.5-second follow-up for its longer default cycle. 170/170 previews rendered successfully. Globe required software WebGL; its canvas appeared, changed its frame fingerprint, and responded to the sampled drag input. The sample recorded no WebGL exception. Unchanged pixels alone do not prove a demo has no motion; use each row’s source trigger and element-state sample as well.

The component table summarizes the source-reviewed motion model and use tags. Runtime counts there are aggregated from each listed variant; docs-only entries without examples retain their page-level audit status. The variant table records its exact configured use and individual browser status.

The snapshot contains seven stale registry/history entries without current source. Five have behavior notes from official v3 documentation. Magic UI maintainers state Arc Timeline never entered production, so there is no released behavior to inspect ([discussion #864](https://github.com/magicuidesign/magicui/discussions/864)). Grid Beams remains an unresolved catalog name with no official source or component page; it is explicitly marked unsupported/unverified and must not be treated as an understood component.
