# Magic UI component review

Generated from the local catalog and official Magic UI docs/source snapshot at commit efe76fc5755eca1142dd4f74c1d6f0ace2887e3c. Use this as a searchable research index, not as approval to put a component on the Flozio homepage. Each row records its motion mechanism, trigger, lifecycle, tags, source status, and available runtime evidence. The seven legacy entries without current source are explicitly marked docs-only or unverified; their behavior is not represented as source-verified.

## Runtime audit

The browser audit visited 77 distinct component documentation routes and checked the first active preview area on each route. 76 previews rendered; 1 route(s) did not produce a usable preview. It sampled two frames about 1.4 seconds apart and separately recorded frame changes and running Web Animations API animations. It moved the pointer over each preview (or its first control) and exercised mapped click, press-and-hold, and drag examples. A changed frame is evidence of visual change during the sample window, not proof by itself that the intended animation worked. This pass sampled the first active preview per route, not all 170 example variants as individual demos.

Current source-backed entries include the installable registry files and docs components present in the local official source snapshot. Seven legacy records have no current source; five have behavior descriptions in official v3 docs, and two have no recoverable official behavior record. Dotted Map source is available and its marker pulse is source-confirmed, but its docs preview did not render in the browser pass.
